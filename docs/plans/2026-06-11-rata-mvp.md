# rata MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Rust MVP of `rata` as an OpenAPI-aware CLI and Postman-style dark TUI.

**Architecture:** The crate exposes a small library for local `.rata/` discovery, OpenAPI operation indexing, URL-to-operation matching, example discovery, and TUI view-model creation. The binary chooses curl-like CLI mode when a URL argument is present and TUI mode otherwise.

**Tech Stack:** Rust 2021, `clap`, `reqwest`, `openapiv3`, `serde_yaml`, `serde_json`, `ratatui`, `crossterm`, `url`, `anyhow`.
